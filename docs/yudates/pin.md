# [POST] /api/yudates/:id/pin

> 認証: 要 | レート制限: なし

## 説明
自分の投稿をプロフィールにピン留めします。ピン留めされた投稿はプロフィールページの上部に表示されます。

## リクエスト

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
|---|---|---|---|
| `id` | number | はい | ピン留めする投稿ID |

### リクエストBody

なし

## レスポンス
### 成功 (200)
```json
{
  "message": "投稿をピン留めしました",
  "pinned": true
}
```
### エラー (403)
```json
{
  "error": "自分の投稿のみピン留め可能です"
}
```
### エラー (404)
```json
{
  "error": "投稿が見つかりません"
}
```

## 実行例
```javascript
fetch("/api/yudates/1/pin", { method: "POST", credentials: "include" })
```

## 備考
- 自分の投稿のみピン留め可能です
- ピン留めは1つの投稿のみ有効です（新しくピン留めすると以前のピンは解除されます）

---

# [POST] /api/yudates/:id/unpin

> 認証: 要 | レート制限: なし

## 説明
投稿のピン留めを解除します。

## リクエスト

### パスパラメータ

| 名前 | 型 | 必須 | 説明 |
|---|---|---|---|
| `id` | number | はい | ピン解除する投稿ID |

### リクエストBody

なし

## レスポンス
### 成功 (200)
```json
{
  "message": "ピン留めを解除しました",
  "pinned": false
}
```
### エラー (403)
```json
{
  "error": "自分の投稿のみ操作可能です"
}
```
### エラー (404)
```json
{
  "error": "投稿が見つかりません"
}
```

## 実行例
```javascript
fetch("/api/yudates/1/unpin", { method: "POST", credentials: "include" })
```

## 備考
- ピン留めされていない投稿に実行してもエラーにはなりません（正常終了）
