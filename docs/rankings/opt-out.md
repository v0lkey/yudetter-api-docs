# [POST] /api/rankings/opt-out

> 認証: 要 | レート制限: なし

## 説明

ランキングから離脱します。離脱後はランキング集計の対象外となり、`/api/rankings` の結果に自身のスコアが表示されなくなります。

## リクエスト

### パスパラメータ

なし

### リクエストBody

なし

## レスポンス

### 成功 (200)

```json
{
  "message": "ランキングから離脱しました"
}
```

### エラー

```json
{
  "error": "ランキングに参加していません"
}
```

```json
{
  "error": "認証が必要です"
}
```

## 実行例

```javascript
fetch("/api/rankings/opt-out", {
  method: "POST",
  credentials: "include"
})
```

## 備考

- 離脱後も既存のランキングデータは保持されますが、集計対象からは除外されます
- 再度参加するには `/api/rankings/opt-in` を使用します
- 参加していない状態で離脱しようとするとエラーが返ります
